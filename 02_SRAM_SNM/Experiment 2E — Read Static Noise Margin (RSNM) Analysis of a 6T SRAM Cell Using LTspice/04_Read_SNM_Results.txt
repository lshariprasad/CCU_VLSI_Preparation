# EXPERIMENT 2E

## TITLE
Read Static Noise Margin (RSNM) Analysis of a 6T SRAM Cell Using LTspice

## SOFTWARE
LTspice 26.0.1

## SUPPLY VOLTAGE
1.8 V

## MOSFET MODEL
Generic Level-1 NMOS and PMOS

## TRANSISTOR DIMENSIONS
- NMOS: W = 2 µm, L = 0.18 µm
- PMOS: W = 1 µm, L = 0.18 µm

## OPERATING MODE
Read Mode

## WORD LINE
WL = 1.8 V

## BITLINES
BL = 1.8 V
BLB = 1.8 V

## ANALYSIS
DC Sweep

## INPUT SWEEP
0 V to 1.8 V

## STEP SIZE
1 mV

## OBJECTIVE
To analyze the read stability of a 6T SRAM cell and extract the Read Static Noise Margin (RSNM) using the butterfly curve method.

## PROCEDURE
1. Construct the complete 6T SRAM circuit using two cross-coupled CMOS inverters and two access transistors.
2. Set the supply voltage to 1.8 V.
3. Precharge both bitlines to 1.8 V.
4. Set the word line to 1.8 V to activate both access transistors.
5. Apply a DC voltage sweep from 0 V to 1.8 V at node Q.
6. Observe the corresponding output voltage at node QB.
7. Export the DC sweep data.
8. Construct the butterfly curve by reflecting the inverter VTC across the diagonal.
9. Determine RSNM using the largest inscribed square in the smaller butterfly lobe.

## OBSERVATIONS
1. Both access transistors are enabled during read mode.
2. Both bitlines are maintained at the supply voltage.
3. The inverter transfer characteristic is affected by the read access transistor.
4. The read disturbance changes the butterfly curve.
5. The largest inscribed square is used to determine RSNM.

## RESULT
Read Static Noise Margin analysis of a 6T SRAM cell was performed using LTspice. The RSNM was determined using the butterfly curve method.

## LIMITATION
The simulation uses generic Level-1 MOSFET models. It does not represent an actual 16-nm FinFET process or a foundry-calibrated transistor model.
